### **To-Do List – README**  

#### **Overview**  
The To-Do List is a server-side web application that allows users to create, update, delete, like, and dislike tasks. It ensures real-time task management with data persistence, user interactions, and a smooth user experience.  

#### **Features**  
- **Add Tasks** – Create new to-do items with descriptions.  
- **Update Tasks** – Edit task details without affecting the layout.  
- **Delete Tasks** – Remove completed or unnecessary tasks.  
- **Like/Dislike Tasks** – Users can like or dislike tasks to show priority or feedback.  
- **Real-Time Updates** – Changes reflect instantly on the UI.  
- **Persistent Storage** – Uses a database to save and retrieve tasks.  

#### **Technology Stack**  
- **Frontend:** HTML, CSS, JavaScript (EJS for templating)  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Atlas)  
- **Icons & UI:** Font Awesome for like/dislike buttons  
- **API Communication:** Fetch API for dynamic updates  

#### **How to Run the Project**  
1. Clone the repository:  
   ```sh
   git clone <repo-url>
   ```
2. Navigate to the project directory:  
   ```sh
   cd todo-list
   ```
3. Install dependencies:  
   ```sh
   npm install
   ```
4. Start the server:  
   ```sh
   npm start
   ```
5. Open in the browser:  
   ```
   http://localhost:3000
   ```
